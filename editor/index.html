Draft Desk

Write, preview, and export newsroom stories
This editor does not publish directly. Drafts stay in your browser until you export them. Review facts and sources, then upload the exported JSON to your GitHub repository. The automated publisher creates article pages from approved entries. Never paste confidential unpublished sources into a public repository.

Story editor

Required for published stories. Verify all factual claims and permissions before selecting Published. Separate paragraphs with a blank line. Plain text only. One per line in the format: Source name: https://example.org

Article preview

Start typing to see your draft.

Publish in four steps

  1. Complete and verify the article, including its sources.
  2. Click Save to export list, then Download articles.json.
  3. Open your GitHub repository → content/articles.json → edit or upload the exported contents and commit.
  4. GitHub Actions validates and generates a separate /article/slug/ page. Check the workflow result.
The JSON export includes all stories loaded from the current public feed plus your edits. Existing unpublicized drafts in GitHub are not included automatically; retain a backup when collaborating.
