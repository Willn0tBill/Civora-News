THE PUBLISHING WORKFLOW

From draft to publication

01

Write and review

Create an article, select its section, and add evidence. Save an unfinished version to this browser.

02

Approve the reporting

Check dates, quotes, source links, copyright and accuracy. The dashboard validates fields, but cannot determine whether a news claim is true.

03

Publish in one commit

Civora Studio sends the approved article to the authorized Cloudflare publisher, which generates website files and commits them to GitHub.

04

Follow deployment

GitHub Pages publishes the new commit. The dashboard provides a link to the commit and the final article URL. Allow for deployment propagation.

Security: Only staff accounts approved in Firebase and listed on the publishing backend can post. The GitHub publishing credential stays in a private Cloudflare secret, not the website.
